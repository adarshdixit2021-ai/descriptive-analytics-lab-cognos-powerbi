RetailPulse Descriptive Analytics Project
This repository contains my lab work and practical files for the Descriptive Analytics project using the RetailPulse dataset.

In this project, I worked with two major business intelligence platforms—IBM Cognos Analytics and Microsoft Power BI Desktop—to build reports, dashboards, and perform data analysis.

🛠️ Tools & Technologies Used
IBM Cognos Analytics: For data source setup, grouped list reports, crosstabs, summary totals, and regional maps.

Microsoft Power BI Desktop: For data modeling, executive KPI summary cards, category-wise charts, time intelligence (YTD calculations), and interactive regional slicers.

📁 What's Inside?
Lab Manual / Report (DA_PulseReport_Dixit.pdf): Contains the complete documentation, step-by-step procedures, and screenshots for all 10 practical experiments (6 Cognos + 4 Power BI).
